# Submarine_RockVsMine_Prediction
This is a Machine Learning Projhect. Where we use sonar dataset from Kaggle to predict the Rock or any Mine for Submarine under the water when any obstacle occure. Using Logistic Regression model we predict whether the obstacle is rock or mine. Here we use Numpy, Pandas, SkLearn to Colletct, Process, Train, Test, Shape the dataset.
